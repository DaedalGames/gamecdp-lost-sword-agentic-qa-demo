GameCDP 핵심 아키텍처

1. Semantic screen understanding

스크린샷을 단순 픽셀 변화로 보지 않고, 로비·전투·보상·HUD 같은 게임 상태와 affordance로 구조화합니다.

2. Intent-based action graph

raw 좌표 매크로가 아니라 battle.start 같은 플레이어 의도를 action graph로 선택하고 실행 증거를 남깁니다.

3. Domain oracle layer

PASS는 화면이 바뀌었다가 아니라 battle.entry, mutation proof, delta event 같은 도메인 oracle이 통과할 때만 발생합니다.

4. Evidence-gated publishing

체크리스트, oracle, contact sheet, customer-visible leak check가 모두 통과한 take만 MP4/GIF로 공개됩니다.

5. Fail-closed QA operations

점검·인증·상점·미검증 mutation은 성공으로 포장하지 않고 blocked/noop으로 남겨, 반복 댓글이나 false positive를 막습니다.
